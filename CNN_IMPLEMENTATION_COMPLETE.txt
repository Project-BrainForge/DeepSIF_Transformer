ARCHITECTURE SUMMARY
================================================================================

CNN2DSpatialFilter:

  Input: (batch, time_steps, 75)
         Tensor from EEG electrodes
    ↓
  Load Electrode Topology:
    • MNE loads anatomy/electrode_75.mat
    • EEGLAB format support
    • 3D → 2D stereographic projection
    ↓
  Convert to 2D Grid: (batch*time_steps, 1, 64, 64)
    • 75 electrodes → 64×64 grid
    • Sparse (only 75 cells filled)
    • Preserves electrode spatial topology
    ↓
  2D Convolutions:
    • Conv2d(1, 32, k=3) → BatchNorm → GELU → Dropout
    • Conv2d(32, 64, k=3) → BatchNorm → GELU → Dropout
    • Conv2d(64, 128, k=3) → BatchNorm → GELU → Dropout
    ↓
  Adaptive Pooling: (batch*time_steps, 128, 4, 4)
    • AdaptiveAvgPool2d((4, 4))
    • Reduces spatial dimensions
    ↓
  Fully Connected: (batch*time_steps, 500)
    • Linear(2048, 500)
    • LayerNorm → GELU → Dropout
    ↓
  Output: (batch, time_steps, 500)
          500-dimensional learned features

  Performance:
    • Parameters: ~2.0M
    • Receptive field: ~7×7 per electrode
    • GPU memory: ~2.5GB (batch size 8)
    • Forward time: ~50ms per batch

TRAINING & EVALUATION PIPELINE
================================================================================

TRAINING (train_cnn.py):
  1. Load dataset (sample_*.mat files)
  2. Create CNN2DSpatialFilter model
  3. For each epoch:
     - Train on batches with gradient clipping
     - Validate without gradients
     - Save best model
     - Check early stopping (patience=15)
  4. Save checkpoints & history

  Commands:
  python train_cnn.py --model_id exp1 --device cuda:0
  python train_cnn.py --model_id exp1 --resume checkpoint.pth  [Resume]
  python train_cnn.py --model_id test --debug                  [Test]

EVALUATION - Simulated (eval_cnn_sim.py):
  1. Load checkpoint & create CNN model
  2. Load test samples (labeled_dataset)
  3. Run inference on 100 random samples
  4. Calculate MSE & correlation
  5. Save results (.mat file)

  Command:
  python eval_cnn_sim.py --model_id exp1 --device cuda:0

EVALUATION - Real (eval_cnn_real.py):
  1. Load checkpoint & create CNN model
  2. Find subject folders in real_data/
  3. For each subject:
     - Load real EEG data
     - Run inference
     - Save per-subject results
  4. Output: {data_dir}/cnn_real_{model_id}.mat

  Command:
  python eval_cnn_real.py --model_id exp1 --device cuda:0

SUPPORT & TROUBLESHOOTING
================================================================================

Issue: ImportError: No module named 'mne'
Solution: pip install mne

Issue: CUDA out of memory
Solution: Reduce batch_size in config_optimized.py or use --device cpu

Issue: Training loss not decreasing
Solution: Check logs, adjust learning_rate, verify data loading

Issue: Electrode file not found
Solution: Run from project root, verify anatomy/electrode_75.mat exists

Issue: Results not saving
Solution: Check directory permissions, disk space, write access
